
# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, inclusive, and harassment-free environment for everyone participating in this project.

## Expected Behavior

All contributors and participants are expected to:

- Be respectful, professional, and considerate.
- Welcome different perspectives and experiences.
- Provide constructive feedback.
- Focus on collaboration and shared learning.
- Respect the privacy and contributions of others.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, discrimination, or personal attacks.
- Offensive comments or inappropriate language.
- Trolling, intimidation, or deliberate disruption.
- Sharing private or confidential information without permission.
- Any conduct that creates an unsafe or unwelcoming environment.

## Scope

This Code of Conduct applies to project spaces, including GitHub issues, pull requests, discussions, and other community interactions related to this project.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the project maintainer through GitHub.

Reports will be reviewed respectfully and handled as confidentially as reasonably possible.

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this Code of Conduct. Repeated or serious violations may result in restrictions on participation.

## Acknowledgment

This Code of Conduct is inspired by the Contributor Covenant community guidelines.
